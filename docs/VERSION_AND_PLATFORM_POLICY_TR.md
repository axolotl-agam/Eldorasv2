# Eldoras V2 — Sürüm ve Platform Politikası

- Hedef platform yalnızca **Minecraft Java Edition** olacaktır.
- Destek tabanı **Minecraft 1.21.4** ve üzeridir.
- Bedrock Edition, Pocket Edition ve çapraz platform desteği hedeflenmez.
- Paper ve Velocity sürümleri seçilirken 1.21.4+ uyumluluğu aranır.
- Java çalışma zamanı, seçilen Minecraft sürümünün resmi gereksinimine göre sabitlenir. 1.21.4 için Java 21 temel alınır; daha yeni Minecraft sürümlerinde Java gereksinimi ayrıca doğrulanır.
- Her eklenti için desteklenen Minecraft/Paper sürümü, Java gereksinimi, lisans ve bağımlılıklar doğrulanmadan pakete eklenmez.
- “1.21.4 ve üstü” hedefi, her eklentinin bütün gelecek sürümlerde otomatik uyumlu olduğu anlamına gelmez. Sunucu için tek bir test edilmiş sürüm seti sabitlenir; yükseltmeler test edilerek yapılır.
